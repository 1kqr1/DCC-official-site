# 部員プロフィールの追加・編集方法

このフォルダに `.md` ファイルを1つ追加すると、`/members` の一覧と `/members/ファイル名` に
プロフィールページが自動で作られます。ログインは不要です。GitHub上でファイルを編集・追加するだけです。

`sample-member.md` を参考にコピーして、内容を書き換えてください。

## frontmatter（--- で囲まれた部分）の項目

- `name`: 名前（必須。これが無い or ファイル名が `_` から始まると一覧に出ません）
- `grade`: 学年（例: `2年`）
- `field`: 関心分野（例: `アプリ開発`）
- `bio`: 一言自己紹介
- `avatar`: 顔写真のファイル名（`public/member-images/` に置く。無ければ人型アイコンが出ます）
- `skills`: 得意なもの・使える技術のリスト（例: `[React, Blender]`）
- `github` / `x` / `discord`: リンク（無ければ表示されません）
- `public`: `false` にするとプロフィール自体を非公開にできます（省略時は公開）
- `order`: 一覧での並び順（小さいほど先に表示。省略可）
- `works`: 作品リスト。各作品は以下を持てます
  - `title`: 作品名
  - `category`: ジャンル（例: `ゲーム`, `Web`）
  - `desc`: 一言説明（任意）
  - `url`: 作品へのリンク（任意）
  - `visible`: `false` にすると、その作品だけを表示から隠せます（省略時は表示）

frontmatterの下に自由に文章（Markdown）を書くと、プロフィールページの本文として表示されます。

## 作品の公開・非公開を自分で切り替えたいとき

自分の `.md` ファイルの中の、該当する作品の `visible: true` を `visible: false` に書き換えて
保存（コミット）するだけで、その作品だけをサイトから隠せます。ページの他の部分は変わりません。
